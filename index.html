RESPALDO Y DATOS

Exportar

Tu biblioteca también es tuya fuera de Papiro.

Exportar lista

Para planillas (Excel) y otros sistemas. Para Aguapey o Koha usá el MARC de más abajo. Columnas: inventario, ISBN, Título, Autor, Editorial, Colección, Materia, CDD, Año, Páginas, Idioma, Ubicación, Notas, Resumen.

Para Aguapey y Koha (MARC21)

Aguapey importa MARC21 en formato ISO (.iso). Koha acepta MARC (.mrc) o MARCXML (.xml). MARC conserva metadatos bibliográficos, pero no transporta las imágenes locales de portada/contratapa ni todos los campos propios de Papiro. Para trasladar una biblioteca completa entre dispositivos, usá la copia JSON.

Copia de seguridad / compartir con otro teléfono

Cada dispositivo guarda su propia lista. Para trasladar la biblioteca completa entre celular y PC, usá Exportar copia JSON e Importar copia JSON: conserva portada, contratapa, inventario y campos propios de Papiro. MARC21 es para intercambiar metadatos con otros sistemas, no para clonar una biblioteca con imágenes.
